# yuec15.github.io

Starter personal site for GitHub Pages.

## Publish

Create a public, empty repository named `yuec15.github.io`. Do not add GitHub's
autogenerated README, license, or `.gitignore`; this folder already has the
initial commit. Then push this folder to the `main` branch. GitHub Pages will
serve the site at:

https://yuec15.github.io/

If Pages does not publish automatically, open the repository on GitHub and go to
Settings -> Pages. Set the source to "Deploy from a branch", choose `main`, and
choose `/(root)`.

## Edit

- Update `index.html` with your real intro, projects, and links.
- Adjust colors and layout in `styles.css`.
- Keep `.nojekyll` if you want GitHub Pages to serve files exactly as committed.
